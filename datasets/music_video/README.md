# Video desde música

Esquema para futuros pares de audio/video con escenas anotadas y alineadas en el
tiempo. Las anotaciones deben describir inicio, fin, contenido visual y relación
con la música; cada registro necesita licencia y procedencia verificables.

Campos requeridos: `source_audio`, `reference_video`,
`scene_annotations_json`, `annotations.language` y `annotations.scenes`.

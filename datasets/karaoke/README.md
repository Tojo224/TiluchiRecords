# Karaoke

Esquema para futuros ejemplos que relacionen video/audio de origen, voz,
instrumental y letra con marcas de tiempo. No contiene medios ni ejemplos
presentados como datos reales.

Campos requeridos: `source_video`, `vocals_audio`, `instrumental_audio`,
`lyrics_json`; `annotations.language`; metadatos comunes descritos en
`../README.md`.
